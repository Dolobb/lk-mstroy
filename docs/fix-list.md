# Список ошибок для исправления за сессию в "Аналитика" и "Самосвалы->Аналитика"
## Для обоих сервисов
[ ] - При расрытии нескольких машин одновременно. переключение между контейнерами-сменами одной машины приводит к переключению на другой машине. Вид контейнеров-смен связан и синхронизирован из-за чего нельзя сравнить разные даты на разных машинах
[ ] - Несмотря на предыдущую проблему, активным подсвечивается только последний выбранный контейнер, а переключаются между сменами по факту сразу несколько контейнеров, и несколько контейнеров-смен могут быть подсвечены активным (оранжевым)
[ ] - Дефолтная дата при открытии / перезагрузке это всегда последний день с обоими выгруженными сменами
[ ] - Контейнеры отражающие объекты вверху (в текущем коде только "самосвалы - аналитика", далее в обоих) - должны быть кликабельны и перелистывать вертикальный скролл до нужного объекта в таблице
## Для самосвалы-аналитика
[ ] - галочку сверху интерфейса "по месту" нужно убрать и в целом убрать фильтрацию "по месту". Добавляем столбец рядом с "рейсы" - "по месту" и там ишем количество смен по месту либо "-" если их не было
## Для "Аналитика"
[ ] - Бокс "ДСТ" (синий) / СМ(оранжевый) под каждым ТС - заменяем на Тип (один из 11, те же самые что указаны сверху в мультифильтрах)
[ ] - В верхней части вместо контейнеров что есть сейчас, делаем контейнеры по объектам, такие же как в "Самосвалы - Аналитика" 
[ ] - Подробное раскрытие самосвалов на доставку должно раскрыать такую же таблицу рейсов + диаграмму как и в "Самосвалы - Аналитика". Абсолютно та же самая логика и тот же самый рендер, зеленую "строку" которая сейчас вместо таблицы ресов + диаграммы убрать вообще
[ ] - Сортиорвка объектов в котрые вложены машины - всегда по количеству ТС по убыванию НО "Без подразделения" всегда в самом низу
