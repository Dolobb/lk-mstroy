## 2. Поиск источника графика топлива
- `getMonitoringStats.fuels[]` — только агрегат окна, поточечного уровня нет.
- `getFuelStats.extData.tankStats[].chargeList/dischargeList` — события заправок/сливов с
  временем, но не ряд уровня.
- Перебор имён команд токен-API → ничего сырого. Выявлена **грабля POST-only** (GET всегда
  «только POST», существование проверять POST'ом → 404).
- Разбор web-интерфейса: **наш `tt.tis-online.com` и НПС — одна платформа tis-online.**
  Сырой ряд — через `servlet/Controller` с web-сессией.

## 3. Сырой ряд топлива — получен для обеих систем
- Наш: `GET_SENSOR_DATA` → 6000 точек/день (шаг ~5с). Сессия снята из браузера (Copy as cURL).
- НПС: вошли через `PASSWORD_MANAGE&act=checkUser` (2FA не понадобилось) → `sessId`+`JSESSIONID`;
  `GET_MO_SENSORS&act=getSensors` → ключ бака (`113629_20093_0`); `act=getSensorsData` →
  ~135 точек/день (шаг ~5 мин). Многодневный диапазон работает одним запросом.
- Запасной путь без сессии — «скользящее окно» getMonitoringStats (`demo_fuel_window.py`).
Детали → [fuel-curve.md](fuel-curve.md), [controller-servlet.md](controller-servlet.md).
