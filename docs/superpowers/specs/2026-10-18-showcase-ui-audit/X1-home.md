# X1 — Главная (/)

Аудитор: Codex, второй аудитор. Дата: 18.10.2026. Основной viewport 1470×830, светлая тема; ключевые состояния — тёмная; начальное — также 1920×1080 и 1280×800. DPR 2 для геометрии. Внешний TopNavBar исключён.

## Чеклист по JSX

- [ ] Начальное состояние: три размера, обе темы.
- [ ] Период списка машин: 1д / 3д / 1н / 1м; без синхронизации.
- [ ] Период таймлайна: 1н / 2н / 4н, + / −; стрелки и drag шкалы.
- [ ] Фильтры моделей; поиск номера, нет совпадений, очистка.
- [ ] Выбрать все / снять все / отдельная машина; прокрутка списка и деталей.
- [ ] Раскрыть/свернуть карточку машины; длинная модель и маршрут; нет заявок.
- [ ] Таймлайн: hover одиночного сегмента и перекрытия; закрепление кликом, hover строки веера, закрытие крестиком/снаружи; ссылка отчёта.
- [ ] Отчёты: Тягачи / Самосвалы / ДСТ, WIP, возврат.
- [ ] Даты: фокус, ввод; dropdown начала/конца маршрута, выбор нескольких, снять все, закрытие снаружи, длинные адреса; «Длинные маршруты».
- [ ] История отчётов: скролл, открыть существующий, «Не сформирован»/пустое состояние при наличии.
- [ ] ДСТ: hover WIP, KPI и таблица, прокрутка до итогов; зум-кроп чисел.
- [ ] Создание отчёта / синхронизация / toast результата — исключены, если требуют POST/изменения данных.
