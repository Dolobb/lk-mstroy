# UI Kit — Мониторинг (Личный кабинет)

Кликабельный прототип редизайна модуля «Самосвалы / Аналитика» с добавленным **видом «Карта»**, сохраняющим всю информацию текущего интерфейса:

- 4 группировки объектов (как и раньше)
- Чипы смен по дням (`30.04 C1 Op`, `10.06 C1 15р` и т.д.)
- KIP-светофор (≥75 / 50–74 / <50)
- Карточки заявок с метриками (рейсы, литры, КИП, расход)
- НОВОЕ: вкладка «Карта» — каждый объект имеет полигон-зону, можно развернуть на полный экран. На зоне отображаются типы ТС (самосвалы оранжевые, КИП-техника синяя, экскаваторы фиолетовые) с тем же набором информации в компактных чипах.

## Файлы

- `index.html` — главный прототип, переключается между Таблица / Карта / Карточки.
- `app.jsx` — корневой компонент со state-логикой.
- `components.jsx` — атомы (TopNav, FiltersBar, ShiftChip, KpiBar, OrderCard, VehicleChip).
- `MapView.jsx` — sandbox-карта с зонами, fullscreen-режимом, пинами ТС.
- `data.js` — мок данных по объектам/ТС/рейсам.

## Как запускать

Открыть `index.html` в браузере. Никаких бэкендов не требуется.
